## Project Overview

This project presents a comprehensive business intelligence dashboard developed in Microsoft Power BI to analyze and visualize quantity performance metrics for Plant Co. throughout 2023 and 2024. Inspired by advanced Power BI visualization techniques and best practices in data analytics, this dashboard provides actionable insights into year-to-date performance, comparative analysis against prior year data, and detailed breakdowns by country, product type, and time periods. The dashboard serves as a powerful tool for business decision-making, enabling stakeholders to quickly identify trends, anomalies, and opportunities for improvement in quantity performance across different market segments.

## Objectives

The primary objectives of this project were to:

- **Create an interactive performance dashboard** that consolidates quantity performance metrics into a single, user-friendly interface with real-time filtering capabilities
- **Implement comparative analysis** between year-to-date (YTD) and prior year-to-date (PYTD) metrics to identify growth trends and performance gaps
- **Develop multi-dimensional visualizations** that break down quantity performance by country, month, and product type to enable granular analysis
- **Design intuitive KPI cards** that provide at-a-glance insights into key performance indicators including total quantity, year-over-year changes, and gross profit percentages
- **Build advanced chart types** including treemaps, waterfall charts, stacked bar charts, and scatter plots to present data in meaningful and visually appealing formats
- **Enable dynamic filtering** through year selection and gross profit metric toggles (Quantity vs. Sales) to support flexible analysis scenarios

## Summary

This Power BI dashboard project transforms raw quantity performance data into a comprehensive analytical tool that empowers business users to make data-driven decisions. The dashboard integrates multiple data sources and dimensions, presenting complex information through carefully designed visualizations that highlight key insights at both summary and detailed levels. The implementation demonstrates proficiency in Power BI's advanced features including DAX calculations for year-over-year comparisons, custom visual formatting, interactive filtering, and multi-chart dashboard design.

The dashboard successfully addresses common business intelligence challenges such as presenting time-series data, comparing performance across different periods, identifying underperforming regions, and visualizing profitability segmentation. Through the use of color coding, conditional formatting, and strategic chart selection, the dashboard makes complex data accessible to users at all levels of technical expertise. The project showcases the ability to balance aesthetic design with functional requirements, creating a dashboard that is both visually appealing and analytically powerful.

## Tools and Technologies Used

- **Microsoft Power BI Desktop** - Primary development environment for creating the dashboard, data modeling, and visualization design
- **Power Query (M Language)** - Data transformation and ETL processes to clean, reshape, and prepare data for analysis
- **DAX (Data Analysis Expressions)** - Advanced calculations for YTD metrics, PYTD comparisons, percentage calculations, and custom measures
- **Power BI Visualizations** - Utilization of native chart types including treemaps, waterfall charts, stacked bar charts, scatter plots, and KPI cards
- **Data Modeling** - Creation of relationships between data tables, implementation of star schema design principles, and optimization of data model performance
- **Power BI Service** - For dashboard publishing, sharing, and collaboration (if deployed)
